## Репозиторий xset_java_course
В директории [src/main/java/school/xset/](https://github.com/svp312312/xset_java_course/tree/master/src/main/java/school/xset) находятся выполненные задания из курса **"Java для тестировщиков"** (школа компании ООО "Иксет", ноябрь-декабрь 2025 г.) 

### Перечень решённых задач

✅ [homework1](https://github.com/svp312312/xset_java_course/tree/master/src/main/java/school/xset/homework1)

  Задача про двух программистов. Создан класс, конструктор, методы, произведена проверка отработки методов в main.
  
✅ [homework2](https://github.com/svp312312/xset_java_course/tree/master/src/main/java/school/xset/homework2)

  Задача на контроллер для GET-запросов. Создан класс с аннотацией @RestController для обработки HTTP запросов.
  
  Созданы методы:
  - для получения текущего времени (с использованием LocalDateTime.now());
  - для получения текущего месяца и определения сезона (с оператором switch - case);
  - для генерации случайной даты в будущем (с методом random.nextInt()).
